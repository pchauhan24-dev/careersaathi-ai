# CareerSaathi AI

CareerSaathi AI is an AI-powered résumé intelligence and mock interview
evaluation platform for students and job seekers.

## Main Features

- Résumé analysis
- Job-description matching
- Skill-gap identification
- AI-generated interview questions
- Voice and text-based mock interviews
- Candidate performance evaluation
- Personalized feedback and reports

## Technology Stack

- React.js and Vite
- Tailwind CSS
- Python and FastAPI
- PostgreSQL
- SQLAlchemy and Alembic
- LLM, NLP and Whisper
