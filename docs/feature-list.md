# CareerSaathi AI: Feature List

**Version:** 1.0
**Document:** Final Feature List
**Last Updated:** August 2026

---

## 1. Overview

This document defines the features planned for CareerSaathi AI. Features are
divided into the initial deployable version and future versions.

The initial version will focus on résumé intelligence, job matching,
personalized mock interviews, performance evaluation, and candidate progress
tracking.

---

## 2. User Authentication Features

- Candidate registration
- Candidate login
- Secure logout
- Password hashing
- Authentication using secure cookies
- Protected application routes
- Login-session persistence
- Authentication error handling
- Current-user verification

---

## 3. Candidate Profile Features

- Create candidate profile
- View profile information
- Edit profile information
- Add education details
- Add work-experience level
- Add technical skills
- Select target job role
- Store profile creation and update dates

---

## 4. Résumé Management Features

- Upload résumés
- Support PDF files
- Support DOCX files
- Validate file type
- Validate file size
- Store résumé information
- View uploaded résumés
- Select an active résumé
- Delete a résumé
- Prevent access to another user's résumé

---

## 5. Résumé Analysis Features

- Extract text from PDF résumés
- Extract text from DOCX résumés
- Identify résumé sections
- Extract candidate skills
- Extract education details
- Extract work experience
- Extract projects
- Extract certifications
- Display structured analysis results
- Generate résumé improvement suggestions

---

## 6. Job-Matching Features

- Enter or paste a job description
- Save job descriptions
- Extract required skills
- Identify important job keywords
- Compare résumé skills with job requirements
- Calculate an overall match score
- Display matched skills
- Display missing skills
- Display partially matched skills
- Generate skill-improvement suggestions
- Save previous job-match results

---

## 7. Interview Configuration Features

Candidates will be able to configure an interview by selecting:

- Target job role
- Experience level
- Interview type
- Difficulty level
- Text or voice mode
- Number of questions

Supported interview types will initially include:

- Technical interview
- HR interview
- Behavioural interview
- Mixed interview

---

## 8. AI Interview Features

- Generate role-based interview questions
- Generate résumé-based questions
- Generate job-description-based questions
- Display one question at a time
- Speak questions using text-to-speech
- Record response time
- Accept typed answers
- Accept recorded voice answers
- Convert speech into text
- Allow candidates to review transcribed text
- Generate dynamic follow-up questions
- Track interview progress
- End or submit an interview session

---

## 9. Answer-Evaluation Features

Each answer will be evaluated using defined criteria:

- Technical correctness
- Answer relevance
- Communication quality
- Answer clarity
- Answer structure
- Response completeness
- Use of suitable examples
- Response time

The evaluation will provide:

- Question-level score
- Written feedback
- Strong points
- Weak points
- Suggested improvements

---

## 10. Performance Report Features

The final report will include:

- Technical-knowledge score
- Communication score
- Relevance score
- Answer-structure score
- Response-time score
- Overall interview score
- Candidate strengths
- Areas requiring improvement
- Question-level feedback
- Personalized practice suggestions
- Final performance summary

---

## 11. Dashboard Features

The candidate dashboard will display:

- Profile completion status
- Latest résumé analysis
- Latest job-match score
- Recent interview sessions
- Recent performance scores
- Total completed interviews
- Progress over multiple interviews
- Quick links to important actions

---

## 12. History Features

Candidates will be able to:

- View uploaded résumés
- View saved job descriptions
- View previous résumé analyses
- View previous job-match results
- View completed interviews
- Open previous performance reports
- Delete selected personal records

- Clear navigation
- Form validation

- Accessible forms and controls

7. Missing-skill identification

## 16. Future Features

The following features may be added after the MVP:

- AI interviewer avatar
- Multilingual interviews
- Company-specific simulations
- Live coding interview mode
- Real-time pronunciation feedback
- Video interview recording
- Facial-expression analysis with user consent
- Job recommendations
- Learning-resource recommendations
- Recruiter dashboard
- Placement-officer dashboard
- Interview scheduling
- Email notifications
- Mobile application
- Exportable PDF performance reports

---

## 17. Features Excluded from the MVP

The following features will not be developed during the initial phase:

- Automatic hiring decisions
- Candidate rejection decisions
- Hidden monitoring
- Emotion detection
- Personality prediction
- Background verification
- Automatic job applications
- Payment and subscription features
- Native Android or iOS applications

These exclusions will keep the initial project practical, ethical, testable, and
possible to complete within the available development time.
